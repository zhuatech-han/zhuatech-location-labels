## 生成编号

选择「按规则生成」，填写库区前缀、排数、每排层数、每层位数、起始编号与数字位数。例如前缀 `A`、3 排、4 层、5 位可生成 60 个编号，从 `A-01-01-01` 到 `A-03-04-05`。

已有编号时，选择「粘贴已有编号」，每行输入一个编号。前导零会保留；出现重复编号时，可点击「移除重复编号」。单次最多生成 1000 张标签。

## 设置标签

- 尺寸：选择预设尺寸，或选择「自定义」并填写宽、高，单位为毫米，范围为 10–200 mm。
- 条形码：适用于英文、数字和常见符号。
- 二维码：支持中文编号。
- 标签打印机：每页一枚标签，PDF 页面尺寸与标签尺寸相同。
- A4 拼版：多枚标签排在一张 A4 纸上，可设置页边距、间距与裁切线。

使用预览的上一张、下一张按钮检查编号，再点击「下载标签 PDF」。

## 打印

1. 用 PDF 阅读器打开下载文件。
2. 选择打印机，在厂商驱动中设置与标签纸一致的宽度、高度和方向。
3. 缩放选择「实际大小」或「100%」，关闭「适合页面」。
4. 选择需要打印的页码范围并打印。

A4 拼版使用整张纸打印后裁切；预切标签纸使用对应版式。扫描标签得到原始库位编号。

## 保存与恢复配置

设置会保存在当前浏览器。点击「导出配置」可下载 JSON 文件；以后点击「导入配置」选择该文件，恢复编号和标签设置。

更换电脑或浏览器时，可用配置文件迁移。点击「载入示例」恢复示例设置。
